## Website Features

The portfolio was developed as a lightweight single-page website with an emphasis on usability, accessibility, responsiveness, and professional presentation.

### Responsive Design

The interface adapts across:

* Desktop computers
* Laptops
* Tablets
* Mobile devices

### Dark and Light Themes

The website provides both dark and light visual themes with persistent theme selection.

### Interactive Dynamic Background

The portfolio includes a custom interactive background implemented directly within the website.

The background includes:

* Animated particles
* Dynamic particle connections
* Mouse-responsive interactions
* Cursor proximity effects
* Ambient gradient motion
* Theme-aware animation colors
* Responsive particle density

The animation system is implemented using native HTML, CSS, JavaScript, and Canvas without requiring a separate animation framework.

### Scroll Animations

Portfolio sections use subtle reveal animations as visitors move through the website.

### Active Navigation

Navigation automatically highlights the section currently being viewed.

### Mobile Navigation

A responsive navigation menu provides an optimized browsing experience on smaller screens.

### Accessibility

The website incorporates accessibility-oriented features including:

* Semantic HTML
* Keyboard focus states
* Skip navigation
* Accessible labels
* Reduced-motion support
* Responsive typography
* Appropriate color contrast

## Running the Portfolio Locally

Clone the repository:

```bash
git clone https://github.com/Samarth-Kumar-Samal-Sam/Samarth-Kumar-Samal-Sam.github.io.git
```

Navigate to the project directory:

```bash
cd Samarth-Kumar-Samal-Sam.github.io
```

Open:

```text
index.html
```

in a modern web browser.

Alternatively, the repository can be served using any lightweight local web server.

For example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Design Philosophy

The portfolio was developed around several principles:

**Professional presentation**
The interface emphasizes readability and content rather than excessive visual decoration.

**Performance**
The website avoids unnecessary frontend frameworks and large animation dependencies.

**Responsiveness**
The layout is designed to work consistently across different screen sizes.

**Accessibility**
Navigation, motion preferences, semantic structure, and keyboard interaction are considered throughout the design.

**Maintainability**
The portfolio uses a straightforward architecture that can be easily updated as new research, projects, publications, and professional experiences are added.
